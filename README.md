# German study pages

Self-contained HTML study pages for learning German (Menschen course). Open the
root `index.html` for the overview, or any `index.html` inside a folder.

- `menschen-a1-2/` – lesson collection
- `vocab-thematisch/` – thematic vocabulary
- `erinnerungswand/lektion-02 … 12/` – memory-wall page per lesson
- `lektion-23-erklaerfilm/` – Lektion 23 explainer

Progress is saved in the browser. Use the round 💾 button (bottom-left) to save
a backup file or restore it on another device.
